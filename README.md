# E-Commerce Sales Analytics Dashboard

## Project Overview
This project analyzes e-commerce sales performance using Power BI and Excel.

## Tools Used
- Power BI
- Microsoft Excel
- DAX

## KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin %

## Features
- Interactive Dashboard
- Region-wise Analysis
- Customer Segmentation
- Sales Trend Analysis
- Profitability Insights

## Business Insights
- Premium customers generated the majority of revenue.
- Technology category showed strong performance.
- Regional analysis highlighted profitable markets.
- Sales trends were analyzed across multiple periods.
